# Shopiva Kenya LTD

**Shopiva** is a Kenyan online marketplace for discovering products, shopping, ordering, delivery tracking, seller tools, M-Pesa payments, and smart shopping assistance.

### Live website

**https://shopiva-keny-ltd.onrender.com/**

Shopiva is built for customers and sellers in Kenya, with prices in KSh and location-aware delivery features.
