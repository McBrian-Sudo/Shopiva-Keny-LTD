📱 Install Shopiva Kenya

One customer shopping experience across phones and computers, powered by the same Shopiva marketplace.

🛍️ Shopiva Customer App

This is the main customer shopping app. It connects to the live Shopiva marketplace for products, accounts, cart, checkout, orders and delivery tracking.

On supported browsers, the Install button will appear automatically.

🏪 Official app stores

Shopiva's customer distribution is intended for Google Play, Apple App Store and other legitimate app marketplaces. Store publication requires the Shopiva developer accounts, signed store builds, store listings, privacy details and each store's review/approval process.

Admin app: never published to customer app stores. It is distributed separately to authorized Shopiva staff.

Windows / macOS / Linux

Open Shopiva in Chrome or Edge and use the install icon in the address bar. It launches in its own app-like window.

ChromeOS

Open Shopiva in Chrome and use Install. The customer app can run in its own window like an installed app.

Android

Use the official Google Play listing when published. Until store publication is complete, Chrome can install the Shopiva customer PWA from this page.

iPhone / iPad

Use the official App Store listing when published. Until then, Safari supports Share → Add to Home Screen for the customer PWA.

🔒 Staff administration is separated from customer shopping. The Admin Control Center uses the Django staff gate, so a normal customer account cannot become an admin by installing or opening an admin client.
