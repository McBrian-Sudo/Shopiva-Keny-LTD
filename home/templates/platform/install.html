📱 Install Shopiva

One Shopiva experience across Android, iPhone, iPad, Windows, macOS, Linux and ChromeOS.

🌍 Shopiva Market App

The customer marketplace is a Progressive Web App. It runs from your browser and can be installed on supported phones and computers without a separate native app.

On browsers that support installation, the Install button will appear automatically.

🤖 Shopiva Delivery

Delivery partners use the dedicated Android app for foreground/background-capable GPS tracking and dispatch operations.

Open Shopiva Market

Windows / macOS / Linux

Open Shopiva in Chrome or Edge, choose the install icon in the address bar, and launch Shopiva like a desktop app.

ChromeOS

Open this page in Chrome and use the Install option. Shopiva can run in its own window like an installed app.

Android

Open this page in Chrome and choose Install app / Add to home screen. Delivery staff should use the dedicated Delivery APK when released.

iPhone / iPad

In Safari, tap Share → Add to Home Screen. iOS will launch Shopiva in an app-like window.

🔒 Shopiva only enables delivery GPS tracking after the delivery partner explicitly starts tracking and grants the required device permission.
