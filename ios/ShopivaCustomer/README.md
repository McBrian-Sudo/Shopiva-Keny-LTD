# Shopiva Customer iOS

Native iOS shell for the main Shopiva Kenya customer marketplace.

The customer shopping application opens the same production Shopiva marketplace used by the web/PWA experience. It is not an admin client.

## App Store target

Apple's current App Store Connect requirement is to build iOS/iPadOS submissions with the iOS/iPadOS 26 SDK or later, using Xcode 26 or later. This repository contains the customer SwiftUI/WebKit source and App Store preparation materials; final App Store signing/upload still requires an Apple Developer team and Apple signing credentials.

## Security

The admin area remains server-protected. The customer application does not contain admin credentials or an admin navigation route.
